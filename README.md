# CareerPath AI

A Streamlit-based AI career guidance platform for 10th and 12th pass students.

Installation

1. python -m venv .venv
2. pip install -r requirements.txt
3. streamlit run app.py

Project structure

- app.py — main launcher
- pages/ — multipage app files
- utils/ — helper modules
- data/ — sqlite DB and sample data
- styles/ — custom CSS

Future enhancements

- Connect to OpenAI for AI Counselor
- Add more career/college data
- Deploy to Streamlit Cloud or Heroku
